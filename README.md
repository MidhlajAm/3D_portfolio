## ✨ Features

- **3D Interactive UI:** Built with `@react-three/fiber` and `@react-three/drei` to render interactive 3D floating shapes in the background.
- **Tactile Project Cards:** Custom 3D pushable button effects for the project showcase, providing a premium, native-app feel on the web.
- **Scroll-Linked Animations:** Utilizing `framer-motion` and `gsap` to trigger buttery smooth reveal animations and scroll-spy navigation as you move down the page.
- **Glassmorphism Design:** Beautiful frosted glass containers (`backdrop-blur`) layered perfectly over 3D backgrounds.
- **Responsive Layout:** Carefully crafted Tailwind classes ensure the UI looks incredible on everything from an iPhone SE to a 4K ultrawide monitor.

---

## 🛠️ Tech Stack

This project is built utilizing a modern React ecosystem:

- **Framework:** React 18 (Bootstrapped with Vite)
- **Styling:** Tailwind CSS + PostCSS
- **Animations:** Framer Motion & GSAP (GreenSock)
- **3D Graphics:** Three.js & React Three Fiber
- **Icons:** Custom SVG and PNG assets
- **Deployment:** Configured for both GitHub Pages (via Actions) and Netlify

## 🚀 Local Development

Want to run this project locally on your machine? Follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### 1. Clone the repository
```bash
git clone https://github.com/MidhlajAm/3D_portfolio.git
cd 3D_portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start the Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

---

## 🏗️ Build for Production

To create an optimized production build, run:
```bash
npm run build
```
This will generate a `dist` folder containing the minified and optimized static assets ready for deployment.

To preview the production build locally:
```bash
npm run preview
```
